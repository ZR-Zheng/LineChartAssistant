# 统计图画板

统计图画板是一款面向中小学数学统计教学的网页工具。教师可以在投影或电子白板上演示怎样把数据画成统计图，制作读图练习和讲义。学生可以录入自己的调查或观测数据，画图、比较数值，并用图表说明结论。

## 快速上手

1. 点击「新建画布」，在工作区左上角的图表类型菜单中选择图表。需要比较多个系列时，先选择「柱状图」，再开启「复式柱状图」。
2. 点击「编辑数据」，在表格中填写类别、系列名称和数值。也可以从 Excel 复制带表头的数据，通过「粘贴整表」导入，或直接导入 CSV / TSV 文件。
3. 查看画布上的图表。讲解时，可以用「标注线」和「文字」指出要比较的数据、标出参考值或记录读图结论。

## 选择图表

| 图表 | 课堂用途 | 示例 |
| --- | --- | --- |
| 折线图 | 观察按时间排列的数据怎样变化 | 一周每日最高气温 |
| 单式柱状图 | 比较不同类别的数量 | 图书角各类书籍的借阅量 |
| 复式柱状图 | 比较多个系列在同一类别中的数值 | 两个班各类图书的借阅量 |
| 扇形图（饼图） | 观察各部分占整体的比例 | 同学们不同上学方式所占的比例 |
| 象形图 | 根据图例把图标数量换算成实际数值 | 每个图标代表 2 本书，各组分别捐了多少本 |

## 用班级数据画图

导入表格时，第一行填表头，第一列放类别名称，后续每列是一个数据系列。同一类别的各系列数值填在同一行。缺失数据可以留空。

例如，把下面的内容复制到「粘贴整表」，依次点击「预览数据」和「替换当前表格」。切换到复式柱状图后，可以请学生找出两个班借阅量相差最多的图书类别。

```csv
图书类别,一班,二班
故事,18,14
科普,12,20
历史,8,6
童话,16,18
```

手动录入时，按 Enter 向下移动，按 Shift+Enter 向上移动。已有表格也可以通过数据面板导出为 CSV。

## 在课堂上边画边讲

- **演示数据和图形的关系。** 在折线图或柱状图中，用「选择」拖动已有的数据点或柱顶，观察图形怎样随数值改变。用「添加点」逐项补上空白数据，也可以开启吸附，让点落在纵轴刻度上。
- **讲解刻度和单位。** 在「坐标轴」中调整轴线及刻度，按需要设置纵轴上限和刻度间隔。新建画布默认显示每个横轴刻度。选中坐标轴后，可以调整刻度标签的字体和字号。
- **引导比较和读图。** 用「标注线」画辅助线或箭头。折线图和柱状图还可以给选定系列添加最大值、最小值或平均值参考线。投影时可以放大画布，或在「画布设置」中关闭数据标签，请学生先根据刻度读数。
- **讲解占比和图例。** 在「扇形设置」中，可以让标签显示数值、百分比或两者。在「象形图设置」中，可以调整每个图标代表的数值，让学生按图例换算。

## 随机生成课堂练习

1. 切换到本节课要练习的图表类型，点击「随机生成」。
2. 选择题材和题型。题材包括校园阅读、运动健康、自然天气、交通出行等。不同图表提供适合的题型，例如读图取数、比较差值、求平均数、分析变化或比较占比。
3. 点击「生成新画布」。选择具体题型或「随机题型」会在图下附上问题。选择「只生成图」可在课堂上自行提问。

同一页面内，按相同的图表类型和题材连续生成时，会先抽完一轮练习场景，再进入下一轮。折线图和柱状图的练习数值是整数，并落在纵轴刻度线上。

## 保存、复用和导出

- 在「画布列表」中切换或复制画布。可以先准备一张课堂示例，再复制一份修改数据，用于学生练习。
- 项目自动保存在当前浏览器。需要在另一台设备上继续编辑时，从「画布列表」里的「项目管理」备份为 JSON 文件，再通过「恢复项目」打开。
- 「导出图片」保存当前画布的图表和标注，并按内容范围裁剪。PNG 可直接插入课件和练习单，SVG 便于缩放和排版。

## 本地运行

安装 Node.js 和 pnpm 后，在项目目录运行以下命令。

```sh
pnpm install
pnpm dev
```

在浏览器中打开终端显示的地址，默认是 `http://localhost:3025`。运行 `pnpm test` 执行回归测试，运行 `pnpm build` 生成生产文件，输出目录为 `dist/`。

# 统计图画板

点击「编辑数据」，可以在表格里修改图表的数值和名称。在折线图和柱状图中，用「选择」拖动已有数据点来调整数值，用「添加数据点」在绘图区为尚未填写的类别添加数值。点击空白处可取消选择，选中对象后可以在工具栏查看和修改它的设置。

- 用「标注线」绘制实线、虚线或箭头线。可以点击当前数据系列的最大值、最小值或平均值辅助线添加标注。按住 Shift 可锁定角度，按住 Alt 可暂时绕过吸附。
- 「坐标轴」可以调整轴线、标题位置和刻度。默认纵轴标题位于轴顶上方居中，横轴标题位于横轴末端右下方。用「选择」拖动轴标题时，可吸附到刻度、轴线、标注和默认标题位置。
- 用「文字」点击画布添加标注。工具栏可设置字体、字号、加粗、斜体、下划线和对齐。颜色设置提供基础色和自定义取色器。
- 选中数据点、坐标轴或标注后，工具栏可调整系列外观、轴线样式、标注不透明度和箭头位置等常用设置。
- 在柱状图的工具栏打开「柱形图标」，可从象形图使用的图标库中挑选图标。每组数据可独立设置单色或彩色图标，图标沿柱高排列，也可随时「恢复普通柱形」。
- 按 Tab 进入画布，用方向键切换对象，按 Enter 或空格编辑。对象工具栏中按 Esc 可返回画布。手柄支持 Alt 加方向键微调。
- 顶部可缩放画布、点击百分比还原缩放，或用「适合宽度」铺满可用空间。放大后可切换到「平移」，用鼠标拖动或方向键移动视图。按住 Ctrl 或 ⌘ 滚动鼠标也可以缩放。
- 「画布列表」按图表标题和类型显示画布，可以新增、复制、切换和删除。删除后可点击「撤销删除」。项目备份、恢复和清空位于「项目管理」。
- 点「随机生成」可按当前的折线图或柱状图类型新建练习画布。随机数据为整数并落在刻度线上，可通过「数据标签」显示具体数值。
- 「橡皮」默认擦除标注。要清除图表数据，可以选中数据点后打开「删除数据…」。
- 「编辑数据」支持从 Excel 粘贴、导入 CSV / TSV 和下载 CSV。文件可使用 UTF-8、带 BOM 的 UTF-16 或 GB18030（兼容 GBK）。第一行填列名，第一列填类别名称，后续各列填数值。空白数值表示缺失数据。长表格可按行范围跳转，Enter 和 Shift+Enter 可跨页录入。
- 在「导出图片」中选择 PNG 位图或 SVG 矢量图。图片按图表及标注的范围导出。

## 本地运行

需要 Node.js 和 pnpm。

```sh
pnpm install
pnpm dev
```

运行回归检查使用 `pnpm test`，生产构建使用 `pnpm build`。
